# Módulo 8: Proxy e Variáveis de Ambiente

Laboratório prático de redes usando apenas comandos bash.

## Comandos utilizados

- `curl`
- `http_proxy` / `https_proxy` (variáveis de ambiente)
- `env | grep proxy`
- `curl --proxy`

## Como executar

Edite os arquivos em `desafios/` e execute um por um:

```bash
bash desafios/desafio01_env_proxy.sh
bash desafios/desafio02_curl_proxy.sh
bash desafios/desafio03_curl_noproxy.sh
bash desafios/desafio04_proxy_info.sh
```

Depois execute a verificação:

```bash
bash testes/verificar_desafios.sh
```
