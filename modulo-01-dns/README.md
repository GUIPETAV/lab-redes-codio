# Módulo 1: DNS e Resolução de Nomes

Laboratório prático de redes usando apenas comandos bash.

## Comandos utilizados

- `nslookup`
- `dig`
- `host`
- `cat /etc/resolv.conf`

## Como executar

Edite os arquivos em `desafios/` e execute um por um:

```bash
bash desafios/desafio01_nslookup.sh
bash desafios/desafio02_dig.sh
bash desafios/desafio03_host.sh
bash desafios/desafio04_resolv_conf.sh
```

Depois execute a verificação:

```bash
bash testes/verificar_desafios.sh
```
