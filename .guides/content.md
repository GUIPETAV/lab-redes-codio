# 🌐 Laboratórios de Redes para Codio

Bem-vindo ao repositório de laboratórios de redes!

Aqui você encontrará 3 módulos práticos para aprender redes usando o terminal Linux.

---

## 📚 Módulos

### [Módulo 1: DNS e Resolução de Nomes](modulo-01-dns)

Você vai aprender a usar comandos como `nslookup`, `dig` e `host` para descobrir IPs e registros DNS.

### [Módulo 2: HTTP e Camada de Aplicação](modulo-02-http)

Você vai fazer requisições HTTP com `curl` e `wget`, além de entender códigos de status e cabeçalhos.

### [Módulo 3: Roteamento e Camada de Rede](modulo-03-roteamento)

Você vai visualizar interfaces, rotas e testar conectividade com `ip addr`, `ip route`, `traceroute` e `ping`.

---

## 🖥️ Como funciona

Cada módulo é um projeto independente no Codio.

1. Abra o módulo desejado
2. Leia o Guide com as instruções
3. Complete os arquivos em `desafios/`
4. Execute cada um no terminal
5. Rode `bash testes/verificar_desafios.sh` para ver sua nota
