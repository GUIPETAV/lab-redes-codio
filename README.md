# Laboratórios de Redes — Codio

Material de aula/atividade prática, organizado para consulta e reuso.

## Visão Geral

Laboratórios práticos de redes de computadores (DNS, HTTP, roteamento), feitos para rodar no terminal via Codio.

## Estrutura do Repositório

| Arquivo | Descrição |
|---|---|
| `modulo-01-dns/` | Laboratório de DNS |
| `modulo-02-http/` | Laboratório de HTTP |
| `modulo-03-roteamento/` | Laboratório de roteamento |
| `.codio` | Configuração do ambiente Codio |
| `.guides/` | Guias de cada laboratório |

## Como Usar

Abra o projeto no Codio (ou ambiente compatível) e siga os guias de cada módulo, na ordem: DNS, HTTP, roteamento.
