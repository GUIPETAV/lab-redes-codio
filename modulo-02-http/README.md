# Módulo 2: HTTP e Camada de Aplicação

Laboratório prático usando apenas comandos bash.

## Comandos utilizados

- `curl`
- `wget`

## Como executar

```bash
bash desafios/desafio01_curl_status.sh
bash desafios/desafio02_curl_headers.sh
bash desafios/desafio03_wget_download.sh
bash desafios/desafio04_post_json.sh
```

Verificação:

```bash
bash testes/verificar_desafios.sh
```
